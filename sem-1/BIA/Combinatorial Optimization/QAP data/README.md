## Dataset

QAP instances can be downloaded from:
https://qaplib.mgi.polymtl.ca/

Place the files inside:

`QAP data/`

The following problems were chosen for the experiments:
- bur26h
- esc16d
- esc32e
- lipa80b
- tai100b
- tai150b
- tai256c
- tai80b
- tho150
- wil100

Thus, the folder `sem-1/BIA/QAP data/` must contain `.sln` and `.dat` files for the indicated QAP instances. For example,
- `tai256c.dat`
- `tai256c.sln`
